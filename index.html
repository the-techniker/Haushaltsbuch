Google Sheets Verbindung
Muss exakt so im Apps Script stehen: var SECRET_TOKEN = "DeinToken". Ohne korrektes Token keine Datenübertragung.
So richtest du Google Sheets ein
  1. Öffne sheets.google.com und erstelle eine neue Tabelle
  2. Öffne im Menü: Erweiterungen → Apps Script
  3. Lösche den vorhandenen Code und füge den Code unten ein
  4. In Zeile 2 dein Token eintragen: var SECRET_TOKEN = "DeinToken"
  5. Klicke auf Bereitstellen → Neue Bereitstellung
  6. Typ: Web-App · Zugriff: Jeder → Bereitstellen
  7. URL + dasselbe Token oben eintragen → Speichern
